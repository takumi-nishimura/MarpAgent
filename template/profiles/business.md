# 次回の受付で仮設案内板を試したい

決めたいことは，案内板を1枚使った試行の可否．

<!-- _section: true -->

## 仮設案内板で小さく試す

**提案**　次回の開催に限り，分岐の手前に受付への矢印を置く．

運営担当は来場者が迷った場所を記録する．常設するかは，当日の観察と設営負担を見て判断する．

---

<!-- _section: true -->

## 設営の手間と当日の対応を比べる

| 判断軸 | 仮設案内板 | 案内係を置く |
| :--- | :--- | :--- |
| 開場前 | 表示を作り，位置を確認 | 担当者を決め，経路を共有 |
| 開場後 | 混雑時の見え方を確認 | 質問に応じて案内 |
| 必要な人手 | 設置と回収を担当 | 開場中は分岐で待機 |

---

<!-- _section: true -->

## 承認後の担当と判断日を決める

| いつ | 誰が | 何をするか |
| :--- | :--- | :--- |
| 開場前 | 会場担当 | 避難経路を避けて設置位置を確認 |
| 当日 | 受付担当 | 道順を尋ねられた場所を記録 |
| 次の運営会議 | 運営責任者 | 継続，修正，撤去のいずれかを決定 |
