# 受付案内の配置と経路選択

初めて会場を訪れる人を対象とした比較計画

---

<!-- _toc: true -->

## 発表の流れ

---

<!-- _section: true -->

## 分岐の手前に案内を置くと，道を選びやすいか

同じ案内板を使い，設置位置だけを変える．初めて分岐に着いたとき，受付に続く通路を選べたかを記録する．

| 条件 | 案内板の位置 | 共通にするもの |
| :--- | :--- | :--- |
| A | 分岐に入る手前 | 矢印，文言，表示サイズ |
| B | 分岐を越えた先 | 矢印，文言，表示サイズ |

---

<!-- _section: true -->

## 最初に受付側を選んだ人数を比較する

| 条件 | 受付側を選択 | 観察人数 |
| :--- | ---: | ---: |
| A：分岐の手前 | 8人 | 10人 |
| B：分岐の先 | 5人 | 10人 |

**図表の読み方**　数値は説明用の架空例．初回の経路選択を集計し，途中で引き返したかは別に記録する．

---

<!-- _section: true -->

## 入口の違いは，配置の効果と区別する

入口によって案内板の見える距離が変わる．本調査では入口ごとに両条件を割り当て，人数と経路選択を報告する．
