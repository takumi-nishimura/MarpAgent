## Slide 7: 富士通インターンへの接続

- Title: インターンで取り組みたいこと
- Layout hint: content (上：中核メッセージ，中：Mermaid フロー，下：貢献領域)
- Content:
    - 正解を代行せず，解けるための足場を設計する
    - これまでの研究：相手の意図が見えないことが協調の難しさになる
    - これまでの研究：行動を上書きせず，意図や操作の手がかりを提示してきた
    - Self-Evolving Agent への展開：検索方針・根拠・次の一手をヒント化する
    - Self-Evolving Agent への展開：実行結果や環境に応じて，自律的に解ける範囲を広げる
    - インターンで発揮したいこと：ヒント設計・過程の可視化・評価実験
- Figure idea:
    - Mermaid で `共有操作研究 → 足場の設計 → Self-Evolving Agent → 自律的な改善` の縦フローを描く
- Speaker note:
    - 共有操作では，教師の行動をそのまま代行せず，学習者が自分で調整できるように意図や操作の手がかりを提示してきた．この考え方を Self-Evolving Agent にも応用し，正解を直接与えるのではなく，検索方針や根拠への注目点をヒントとして与え，エージェントが自律的に解ける範囲を広げる設計・実装・評価に取り組みたい．
- Takeaway:
    - **人の能力発揮を支える協調設計の視点を，Self-Evolving なマルチエージェントの設計・評価へ接続する**
