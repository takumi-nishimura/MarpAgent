# 比較の範囲と選択規則

対象は ISS-0047 の未達項目「標準例の個別指定が減り，例外の調整手順が短く明確になったこと」である．寸法宣言だけの削減，見かけの大型化，validator の合格だけでは完了としない．

## 固定する条件

`6a6c9433cc0f893b20d5f40fbfa52d990591d103` の lab／muji／toshiba CSS を各テーマの両方式に同一に使う．旧方式とはこの CSS 上の従来 markup と utility であり，10月21日の旧 CSS との比較ではない．現行 lab の typography を含め，フォント・文字寸法・太さ・行間・字間・強調色を方式間で照合する．テーマ間の typography は各テーマ本来の値を保つ．

既存 fixture の単図，不均等8:4列，二図の縦積み，結果図＋補足の4標準例と，縦長列，下段キャンバス高増加，長脚注の3境界例を再利用する．各系列に元の内容，見出しへの追記，最後の caption への追記を用意する．合計21ケース×3テーマで，変更する語句は `recipes.cjs` に固定する．一つの比較組の本文・SVG・alt・caption・脚注は同じであり，短縮，手動改行，crop は使わない．

HTML に従来と同じ Noto Sans JP variable TTF，SVG に同じ27文字の subset を埋め込み，すべての HTTP(S) 要求を遮断する．1280×720，DPR 1，Chromium を使い，CDP で見出し・caption の実使用フォントを確認する．

## 修復候補と負担の数え方

旧方式は各 figure ごとに無修正，`w-full`，`w-3/4`，`w-1/2`，`w-1/3`，`w-1/4` を列挙する．二図では直積36候補を使うため，一方だけの修正を見落とさない．機械条件を満たす候補のうち追加 utility 数が最少のものを選び，同数なら最小図内ラベル寸法が最大のものを選ぶ．これは有限候補内の最少であり，すべての CSS の大域最適や美観の順位ではない．

縦長列では figure 全体の `height: 460px` 1宣言も別経路として測る．見出し増加時の最も狭い残余領域（toshiba の旧 figure 上端203.75pxから672pxまで）を20px刻みで切り下げた共通値であり，caption を含む．この経路が全増加条件に通るなら，幅 utility の再選択を旧方式全体に不可避の再調整とは呼ばない．

body は `.body` を追加し，grid の列幅・gapを保持して `.fill` と図側の `.box` で高さをつなぐ．説明側には不要な `.box` を加えない．縦積みは `.body` と既存 `gap-4` と同じ `--body-gap: calc(var(--spacing) * 4)` を使う．単図・結果では `.body` 1 wrapper だけを加える．

現行 lab の長脚注には，既定の body 下端672pxに対して脚注上端667.8125pxという領域干渉がある．本文 glyph 同士の衝突を validator が検出したという意味ではない．この組は既定結果を残し，公開変数 `--body-bottom-safe: 56px` 1宣言を加えた経路も測る．56px は脚注上端より1px以上上に本文領域を収める reserve を4px刻みで切り上げた値である．

wrapper，class token（重複も対象要素ごと），幅 utility，inline 宣言，case 固有サイズ宣言，構図維持の gap parameter を別々に数える．幅 utility は class 数の内数であり，加算した総合スコアは作らない．`figure`／`figcaption` と脚注要素は配置 wrapper から除くが，`.footnote` は総 class 数に含める．元からある列比率指定を削減と数えない．ロゴ無効化は両方式共通の環境制御であり，case 調整に数えない．

再調整は，系列の元の内容に選んだ指定を見出し増加・caption 増加へ持ち越し，条件を満たさなくなった場合に変更する対象要素数とする．すべての増加条件を一つの指定で満たす候補も別に記録する．試行数は実測作業時間や人間の試行錯誤回数の推定に使わない．

## 判定と視覚確認

既存 audit の clipping／overlap／small-text／edge-crowding を保存する．比較上の収まりは，これら0件，本文下端673px以下（672px＋測定許容1px），脚注要素への非侵入，contain，図内ラベル12px以上をすべて満たすこととする．12px は旧証跡に合わせた下限であり，快適な投影可読性の保証ではない．SVG 内ラベルは元寸法24px／28pxと contain の描画倍率から計算する．

内容 hash，semantic text 要素の typography hash，alt と素材順，列の幅・位置，縦積みの gap を方式間で assert する．行数・図の寸法・脚注との距離は別に測る．画像で条件A／B，52／68，任意単位，共通入力，入力→処理→出力の矢印，caption，強調，留保，出典を確認する．内容理解や投影距離の実験は行わない．

## 校正と履歴

10月21日の committed 証跡は変更しない．10月30日の pilot では，inline `1rem` と Marp が変換する theme の `gap-4` が16px対26pxとなる不一致を検出し，同じ spacing 式へ直した．また muji の縦積み caption が増加しても1行のままだったため追記を延長し，列 caption は lab で3行となったため短い同義の追記へ統一した．変更はすべて両方式に同じように適用する．pilot 由来の負担値は最終比較と混ぜない．固定高さと脚注 reserve は上記の寸法から選び，最終 run で再確認する．

旧方式の修復不要例も保持する．一般的な削減が示せない場合，支持できた範囲と未解決の受入判断を残し，ISS を閉じない．共有 CSS／依存／workflow を変更する必要があるときだけ，担当範囲を確認して別の実装と検証に分ける．
