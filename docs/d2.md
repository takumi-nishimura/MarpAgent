# D2 diagrams

`d2` フェンスは共通 Marp engine で SVG に描画される．serve，overview，検証，HTML／PDF／PPTX／画像出力，screenshot で同じ処理を使う．Mermaid は従来どおり使える．

````markdown
```d2
direction: right
input: Input
output: Output
input -> output
```
````

固定対応版は **D2 0.9.0**．ホストへ明示的に導入する．実行時の自動ダウンロードや更新は行わない．D2 を使わない原稿は D2 未導入でも動作する．`.mise.toml` に版を固定しており，`mise install d2@0.9.0` で導入できる．別の導入方法では実行ファイルを PATH に置くか，`MARP_AGENT_D2_PATH` に単一の実行ファイルのパスを指定する．コマンド文字列や追加引数は渡せない．`marpx --doctor` は解決先，版，TALA の有無を示す．

## Settings and reproducibility

既定は TALA，seed は `[1; 2; 3]`．D2 本体の既定とは異なる．次の1行を前置きしてコンパイルし，原稿内の D2 標準設定を優先する．

```d2
vars: {d2-config: {layout-engine: tala; data: {tala-seeds: [1; 2; 3]}}}
```

原稿では `vars: {d2-config: {layout-engine: elk}}` のように変更できる．対応する配置エンジンは `tala`，`elk`，`dagre` のリテラル指定．独自フェンス引数はエラーになる．コード例として表示する場合は `text` などのフェンスを使う．

0.9.0 の検証結果では，`vars: null` は前置きした設定を消して D2 本体の既定へ戻す．`vars: {d2-config: null}` は前置きした設定を残す．`layout-engine` は明示した CLI flag／環境変数が原稿より優先される．TALA の `data.tala-seeds` は例外であり，固定版の `d2 layout tala` は原稿の data が flag より優先すると説明する．アダプターは layout／seed flag を付けず，継承した `D2_*` と `DEBUG`，`SCALE`，`OMIT_VERSION`，`IMG_CACHE`，`BROWSER`，`HOST`，`PORT` を取り除く．watch，bundle，target，animation，timeout，出力先はアダプターが固定する．mise shim は元のプロジェクト文脈で実体へ解決し，実体の内容をハッシュする．

## Japanese and math

D2 の同梱 Latin font には日本語の字形がない．日本語などを含む図では，利用者が用意した適切な TTF を明示する．

```sh
MARP_AGENT_D2_FONT_PATH=/path/to/Japanese-font.ttf npm run marpx -- decks/example/slide.md --html
```

このファイルを通常・太字・semibold・monospace の計測と埋込に共通使用する．斜体は `MARP_AGENT_D2_FONT_ITALIC_PATH` へ別に明示したときだけ置き換える．0.9.0 では Regular TTF を斜体 slot へ流用すると TALA 内部エラーになる例を再現したため，通常書体から自動流用しない．指定のない斜体は D2 の同梱書体を使い，日本語の斜体が必要なら対応する TTF を明示する．フォントのライセンスは利用者が確認する．OS のフォントを検索・収集・配布する処理はない．生成 SVG の実際に選ばれた埋込 font face と非 ASCII 文字の字形を検査し，不足を fallback font で隠さない．各ファイルの内容ハッシュをキャッシュキーへ含める．variable font の weight は実画像で確認し，CI の受入には固定 Regular TTF を使う．

数式は D2 標準の LaTeX block label を使う．Mermaid 向け MathJax 後処理は適用しない．

D2 の edge label は既定で斜体になる．通常書体の日本語 label を使う場合は `a -> b: 方針 {style.italic: false}` のように D2 原稿で明示する．日本語の斜体を使う場合は対応する斜体 TTF を指定する．TALA が特定の font face で内部エラーになる場合は，対応する書体を選ぶか，原稿の配置を `elk` に変更する．renderer が配置や書体を黙って切り替える処理はない．

```d2
formula: |latex
x^2 + \alpha = \frac{1}{2}
|
```

## Scope and layout

初版はフェンス内で完結する単一の静的図を対象とする．import，icon／image，link，layers／scenarios／steps，animation，外部配置プラグインは未対応として拒否する．Markdown label 内のリンク・画像・HTML も拒否する．CLI の bundle は明示的に無効化する．ソースの能力検査は保守的な字句検査であり，D2 CLI のサンドボックスではない．対象は信頼済みのローカル原稿であり，未信頼原稿の実行隔離を保証しない．

block label は上記の数式例のように，終端の `|` を単独行に置く複数行形式を使う．初版は inline block label を拒否する．Markdown block 内の substitution も外部参照を隠せるため拒否する．

SVG は HTML へ直接埋め込み，XML／CSS の構文解析で外部参照，script，event 属性，未解決参照，重複 ID，非静的要素，壊れた寸法・フォントを拒否する．ID と参照を揃えて図ごとに変換し，CSS selector と埋込フォント名も隔離する．BudouX は図の subtree を変更しない．計測済みラベルの font-size を保持する．D2 の theme-id などは尊重し，Marp の配色を自動変換しない．

`.d2-diagram` は縦横比を保って幅内へ収め，crop しない．`--d2-width` と `--d2-max-height` で全体の表示寸法を調整できる．slide の既定上限は 500px，paper は上限なし．図内の文字を CSS で拡大する操作は再計測にならないため使わず，原稿の D2 設定を修正する．長いラベルや図全体を縮小した際の可読性は実際の画像で確認する．

## Failures and cache

プレビューではエラー，原稿の slide／line，元のコードを表示する．validation はブラウザが起動しなくても `diagram-render-error`，`engine: d2` を報告する．HTML／PDF／PPTX／画像／screenshot は失敗を残したまま成功せず，既存出力へ書き込む前に停止する．

共通 engine の戻り値は `d2Diagnostics` を持つ．HTML は `data-marpagent-render-error="d2"` と診断・原稿位置の属性を持つ．別の export route は **既に描画した HTML** に対して `src/d2-diagnostics.js` の `assertD2RenderSucceeded(html)` を呼ぶ．失敗時は `code: D2_RENDER_FAILED`，`diagnostics` 配列を持つ例外になる．ブラウザと再コンパイルは不要であり，ZIP 出力にも同じ検査を使う．

入力上限は 1 MiB，stdout／stderr はそれぞれ 16 MiB，図単位の既定 timeout は 30000ms．`MARP_AGENT_D2_TIMEOUT_MS` で実行上限を明示変更できる．非ゼロ終了は部分 SVG が出ていても失敗とする．supervisor が timeout／出力超過で子孫プロセスを終了する．

成功し検査を通った SVG だけを `node_modules/.cache/marpagent-d2/` へ原子的に保存する．入力・前置き・実効 flag・D2 の実体と版・フォント内容・salt・アダプター／SVG 検査処理と parser の版をキーにする．cache hit でも SVG を検査する．`MARP_AGENT_D2_CACHE=0` で無効化，`MARP_AGENT_D2_CACHE_DIR` で保存先を変更できる．削除後は原稿から再生成する．デッキに `.d2` や `.svg` の管理ファイルを生成しない．

## Acceptance commands

`npm test` は擬似実行ファイルで runner・cache・フェンス・失敗を検査する．`npm run test:d2` は実際の D2 0.9.0 と日本語対応 TTF を必須にし，不足時に skip しない．

```sh
MARP_AGENT_D2_PATH=/path/to/d2 MARP_AGENT_D2_FONT_PATH=/path/to/Japanese-font.ttf npm run test:d2
```

GitHub CI は固定版 D2 とテスト専用の日本語フォントを明示導入して受入試験を実行する．配布 HTML のオフライン表示，図内の字形，縦横比，印刷・PDF・PPTX の見た目も実際の成果物で確認する．

CI の日本語フォントは SHA-256 を確認した Noto Sans JP を fonttools 4.60.1 で weight 400 に固定する．fonttools は試験準備だけに使う．M PLUS 1p では字形が存在しても一部 label の高さ計測と実際の描画位置がずれる例があったため，任意の TTF の計測精度を字形検査だけで保証しない．固定版受入では label が node 枠内に収まることもブラウザで検査する．
